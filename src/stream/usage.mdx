# Usage

## Starting the stream

Starts the stream.

`podcast-radio --start myStream`

**Shorthand:** -s

You can also ommit the --start flag.

`podcast-radio myStream`

## Help

`podcast-radio --help`

**Shorthand:** -h

## Generate a project

`podcast-radio -generate myStream`

**Shorthand:** -g

## Override Stream Output

Overrides the stream_url/stream_key config. Useful for testing output and development.

`podcast-radio --output='rmtp://example.org'`
